# Лабораторні роботи з дисципліни "Організація баз даних та знань"

## Виконав: Мищишин Олег Михайлович (ІР-21)

## Лабораторна робота №4 (Варіант: instagram)

Проєкт реалізує серверну частину (Back-End) для управління реляційною базою даних `instagram_db` на Node.js та Express. 

Забезпечено підключення до MySQL через пул з'єднань, виконання CRUD-операцій для таблиць та опрацювання запитів для зв'язків M:1 і M:M згідно з вимогами. Тестування API виконано через Postman.
